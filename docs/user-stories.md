# User Stories

## Visitor

1. As a visitor, I want to browse published listings without creating an account, so that I can look for a room before committing to sign up.
2. As a visitor, I want to search listings by neighborhood, maximum rent, availability date, and amenities, so that I only see rooms that fit what I need.
3. As a visitor, I want to see a listing's photos, description, rent, and the property's amenities, so that I know what I'm looking at before applying.
4. As a visitor, I want to read the reviews left on a property, so that I know what past visitors thought of it before I decide to sign up and apply.

## Member — as host

5. As a member, I want to register a property with its address, neighborhood, type, and amenities, so that I can offer rooms in it.
6. As a member, I want to publish a listing for a free room in my property, so that seekers can find and apply to it.
7. As a member, I want to save a listing as a draft before publishing it, so that only I can see it while I'm still writing it.
8. As a member, I want to upload photos of the room and the shared spaces to my listing, so that seekers know what they're applying to.
9. As a member, I want to see every application received on my listings, so that I can decide who to consider.
10. As a member, I want to shortlist an application, so that I can move forward with arranging a visit for that applicant.
11. As a member, I want to propose a visit on a date and time for a shortlisted application, so that the seeker can see the room in person.
12. As a member, I want to cancel a visit and propose another one, so that I can reschedule without losing the application.
13. As a member, I want to accept one application on a listing, so that the room is reserved for that seeker and every other pending or shortlisted application on it is automatically rejected.

## Member — as seeker

14. As a member, I want to apply to a listing with a message, my move-in date, and how long I intend to stay, so that the host has what they need to consider me.
15. As a member, I want to withdraw an application I sent, so that I'm no longer considered for a room I'm no longer interested in.
16. As a member, I want to see the state of every application I've sent, so that I know whether I'm still pending, shortlisted, accepted, or rejected.
17. As a member, I want to confirm a visit a host proposed, so that we both know the viewing is set.
18. As a member, I want to leave a review of a property after a completed visit, with a rating and a comment, so that future seekers know what to expect.
19. As a member, I want to save a listing I'm interested in, so that I can find it again later without searching for it.
20. As a member, I want to report a listing that looks fraudulent or misleading, so that moderators can look into it.

## Moderator

21. As a moderator, I want to see every reported listing, so that I can review what people have flagged.
22. As a moderator, I want to take down a listing that violates the platform's rules, so that it stops being visible to seekers.
23. As a moderator, I want to remove a review that's abusive or clearly false, so that the property page stays trustworthy.
24. As a moderator, I want to add, edit, or remove neighborhoods from the catalog, so that hosts always have an accurate list to choose from.
25. As a moderator, I want to add, edit, or remove amenities from the catalog, so that listings describe what they actually offer using a consistent set of options.
